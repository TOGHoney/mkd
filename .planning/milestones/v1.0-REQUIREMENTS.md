## Shipped Requirements

### 1. Ingestion Pipeline (FastAPI)
- [x] **INGEST-01**: Async crawler crawls HTML/SPA web pages up to depth limit with domain-fencing.
- [x] **INGEST-02**: Traverses XML sitemaps to discover documentation URLs.
- [x] **INGEST-03**: Strips boilerplate (nav, footer, ads) to extract clean Markdown.
- [x] **INGEST-04**: Computes SHA-256 document content hashes to avoid duplicate indexing.

### 2. Chunking & Embeddings (Local FastEmbed)
- [x] **EMBED-01**: Local FastEmbed ONNX runtime with `BAAI/bge-small-en-v1.5` (zero API cost, sub-10ms latency).
- [x] **EMBED-02**: Produces normalized 384-dimensional dense vector embeddings.
- [x] **EMBED-03**: Chunks text recursively (500–800 tokens, 100 overlap) respecting markdown headings.
- [x] **EMBED-04**: Injects document title, URL, and section breadcrumbs in chunk prefix.

### 3. Vector Database (Qdrant)
- [x] **VECT-01**: Qdrant vector database storage with `company_memories` collection.
- [x] **VECT-02**: Indexes `workspace_id` in Qdrant payload schema for tenant isolation.
- [x] **VECT-03**: Idempotent upsert operations with deterministic UUID5 point IDs.

### 4. Semantic Search & Grounded Generation (RAG)
- [x] **RAG-01**: Vector search with mandatory `workspace_id` payload match, mathematically preventing cross-tenant leakage.
- [x] **RAG-02**: Retrieves top-k relevant chunks with similarity score thresholding.
- [x] **RAG-03**: Grounded prompt enforcing zero hallucination and source citation.
- [x] **RAG-04**: Groq Llama 3.3 70B token streaming via Server-Sent Events (SSE).

### 5. Multi-Tenant Authentication & Workspace Control (Node.js + MongoDB)
- [x] **AUTH-01**: JWT authentication for company admins (login/register).
- [x] **AUTH-02**: Default workspace, API key (`sk_live_...`), and widget key (`wk_live_...`) auto-generation.
- [x] **AUTH-03**: Widget key public validation with Origin/Referer domain whitelist.
- [x] **AUTH-04**: Strict multi-tenant isolation via `requireWorkspaceAccess` guard.

### 6. Background Queue & Rate Limiting (BullMQ + Redis)
- [x] **QUEUE-01**: Submitting source pushes job to BullMQ returning HTTP 202 Accepted.
- [x] **QUEUE-02**: BullMQ worker orchestrates crawl in FastAPI and updates status.
- [x] **QUEUE-03**: Polling (`/jobs/:id`) and SSE (`/jobs/:id/progress`) progress streams.
- [x] **QUEUE-04**: Chat gateway verifies `widget_key`, `Origin`, and sliding-window rate limit (30 req/min).

### 7. Embeddable Chat Widget (Vanilla JS + Shadow DOM)
- [x] **WIDG-01**: Zero-dependency standalone JavaScript bundle (`widget.js`) <40KB (actual: 23.68 KB).
- [x] **WIDG-02**: Entire widget UI is encapsulated inside Shadow DOM (`attachShadow({ mode: 'open' })`).
- [x] **WIDG-03**: Widget renders a floating launcher badge and responsive collapsible chat window with customizable theme colors.
- [x] **WIDG-04**: Widget connects to the streaming chat API and renders typewriter streaming text with markdown support.
- [x] **WIDG-05**: Widget displays clickable source citations at the bottom of assistant responses.

### 8. Company Admin Dashboard (React + Tailwind)
- [x] **DASH-01**: Modern dashboard displaying workspace overview, active sources, and widget configuration.
- [x] **DASH-02**: Sources view allows adding websites, triggering crawls, and inspecting real-time progress bars.
- [x] **DASH-03**: Widget Customizer provides real-time preview of chat bubble position, brand colors, bot name, and welcome greeting.
- [x] **DASH-04**: Embed Modal provides one-click copy of the `<script>` tag with the workspace's widget key.
- [x] **DASH-05**: Conversation Logs view displays past user queries, bot answers, retrieved citations, and latency metrics.
