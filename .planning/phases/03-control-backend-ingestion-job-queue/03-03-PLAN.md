<objective>
Build the public widget gateway layer: domain whitelisting, Redis sliding-window rate limiting, configuration retrieval, conversation session persistence, and SSE stream proxying between the embeddable chat widget and the FastAPI RAG engine.

Purpose: Protects the AI backend from unauthorized third-party embedding, scraping, and denial-of-service bursts while streaming grounded RAG responses to website visitors.
Output: Widget auth middleware, rate limiter, chat streaming proxy, conversation log store, and test suite.
</objective>

<threat_model>
- T-03-04: API scraping and denial-of-service attacks on public widget endpoints (ASVS 13.2). Mitigation: Redis sliding-window rate limiter throttles clients exceeding 30 requests/minute per IP, returning HTTP 429.
- T-03-05: Unauthorized embedding / origin spoofing using stolen widget keys (ASVS 4.3). Mitigation: `requireWidgetAuth` validates request `Origin` and `Referer` against `workspace.allowed_domains`; mismatches return HTTP 403 Forbidden.
</threat_model>

<task type="auto">
  <name>Task 2: Origin Domain Whitelist Middleware & Redis Rate Limiter</name>
  <files>backend-node/src/middlewares/widgetAuth.js, backend-node/src/middlewares/rateLimiter.js</files>
  <read_first>backend-node/src/models/Workspace.js, backend-node/src/config/redis.js, .planning/research/PITFALLS.md</read_first>
  <action>
    1. Create `backend-node/src/middlewares/widgetAuth.js`:
       - `requireWidgetAuth(req, res, next)`:
         - Extracts `widget_key` from header `x-widget-key`, `Authorization: Bearer <key>`, or query param `widget_key`.
         - If missing, returns HTTP 401 Unauthorized (`{ error: 'Widget key required' }`).
         - Queries `Workspace.findOne({ widget_key })`.
         - If workspace not found, returns HTTP 401 (`{ error: 'Invalid widget key' }`).
         - Validates Origin:
           - Extracts origin hostname from `req.headers.origin` or `req.headers.referer`.
           - If `workspace.allowed_domains` contains `'*'`, bypasses domain check.
           - Otherwise, checks if hostname matches any allowed domain (supports exact match or wildcard `*.domain.com`).
           - If origin is null, empty, or unapproved, returns HTTP 403 Forbidden:
             `{ error: 'Origin domain not authorized for this widget' }`.
         - Attaches `req.workspace = workspace`.
         - Calls `next()`.
    2. Create `backend-node/src/middlewares/rateLimiter.js`:
       - `widgetRateLimiter(options)`:
         - Window: 60 seconds. Limit: 30 requests per IP per workspace.
         - Uses Redis key `ratelimit:${workspaceId}:${clientIp}` with TTL (or in-memory Map fallback for offline test environments).
         - Increments count. If count > limit, returns HTTP 429 Too Many Requests:
           `{ error: 'Rate limit exceeded. Please wait a moment.' }`, sets `Retry-After: 60`.
  </action>
  <verify>node -e "const a = require('./backend-node/src/middlewares/widgetAuth'); const r = require('./backend-node/src/middlewares/rateLimiter'); console.log('Widget auth and rate limiter loaded')"</verify>
  <acceptance_criteria>
    - Missing or invalid `widget_key` returns 401
    - Unapproved `Origin` header returns 403
    - Rate limiter returns 429 with `Retry-After` header when limit exceeded
  </acceptance_criteria>
  <done>Domain whitelist security and Redis sliding-window rate limiter created.</done>
</task>

  <files>backend-node/src/controllers/widgetController.js, backend-node/src/controllers/conversationController.js, backend-node/src/routes/widgetRoutes.js, backend-node/src/routes/conversationRoutes.js, backend-node/src/server.js, backend-node/tests/widget_gateway.test.js</files>

  <action>
    1. Create `backend-node/src/controllers/widgetController.js`:
       - `getWidgetConfig(req, res)`:
         - Public endpoint returning `{ bot_name, primary_color, welcome_message, position }` from `req.workspace.widget_settings`.
       - `handleWidgetChat(req, res)`:
         - Validates input body: `{ message, session_id }`.
         - Sets SSE streaming response headers (`Content-Type: text/event-stream`, `Cache-Control: no-cache`, `Connection: keep-alive`).
         - Records start timestamp for latency measurement.
         - Proxies chat query to FastAPI service (`POST http://localhost:8000/api/v1/rag/query`):
           `{ workspace_id: req.workspace._id.toString(), query: message }`.
         - Streams tokens back to client using SSE chunks: `data: JSON.stringify({ token })\n\n`.
         - Accumulates streamed text and citations.
         - On stream end:
           - Calculates `latency_ms = Date.now() - startTime`.
           - Asynchronously logs conversation in MongoDB `Conversation` model with user query, assistant response, citations, user IP, origin, and latency.
           - Emits final event `data: [DONE]\n\n` and terminates response.
         - If FastAPI is unreachable or fails: emits polite fallback message via SSE and terminates gracefully without throwing 500 unhandled exceptions.
    2. Create `backend-node/src/controllers/conversationController.js`:
       - `getConversations(req, res)`:
         - Protected endpoint (`requireAuth` + `requireWorkspaceAccess`).
         - Queries `Conversation.find({ workspace_id }).sort({ createdAt: -1 }).limit(50)`.
         - Returns conversation list with message count and latency metrics for the dashboard.
    3. Register routes:
       - `src/routes/widgetRoutes.js`:
         - `GET /api/v1/widget/config` -> `[requireWidgetAuth, widgetController.getWidgetConfig]`
         - `POST /api/v1/widget/chat` -> `[requireWidgetAuth, widgetRateLimiter, widgetController.handleWidgetChat]`
       - `src/routes/conversationRoutes.js`:
         - `GET /api/v1/conversations` -> `[requireAuth, requireWorkspaceAccess, conversationController.getConversations]`
       - Mount routes in `backend-node/src/server.js`.
    4. Write test in `backend-node/tests/widget_gateway.test.js`:
       - Tests `widget_key` authentication and rejection of missing/invalid keys.
       - Tests domain whitelist blocking forged origin (`http://evil-site.com`).
       - Tests rate limiter throttling requests upon exceeding burst ceiling.
       - Tests conversation persistence recording query, answer, and latency.
  </action>
