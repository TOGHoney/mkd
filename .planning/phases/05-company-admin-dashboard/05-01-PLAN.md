<objective>
Scaffold the modern React + Tailwind CSS company admin dashboard (`frontend-dashboard/`) with Vite. Implement the core design system (dark mode, glassmorphic cards, luminous gradients), global authentication & workspace state contexts, navigation shell (Sidebar, Header), and the primary Workspace Overview view with API/Widget key management and allowed domain controls.

Purpose: Provide company administrators with a command center to view their workspace telemetry, manage developer credentials, and navigate the platform.
Output: Production-ready React dashboard shell in `frontend-dashboard/`, Auth & Workspace contexts, Workspace Overview page, and verification test suite.
</objective>

<threat_model>
- T-05-01: Cross-Site Scripting (XSS) via workspace name or user inputs (ASVS 5.3). Mitigation: React native JSX entity escaping for all dynamic strings.
- T-05-02: Exposure of secret API keys in UI (ASVS 3.1). Mitigation: Sensitive `api_key` (`sk_live_...`) masked by default with toggle to reveal and secure clipboard copy.
- T-05-03: Cross-tenant data leakage in client state. Mitigation: Requests strictly inject `Authorization: Bearer <jwt>` and `x-workspace-id` headers verified by backend middleware.
</threat_model>
