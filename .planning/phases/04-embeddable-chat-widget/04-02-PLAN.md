<objective>
Implement the streaming chat integration, lightweight markdown parser, and citation badge pills, then configure Vite to compile the entire custom element into a single, self-contained `<40KB` standalone script (`dist/widget.js`) embeddable via a single `<script>` tag.

Purpose: Delivers the core visitor user experience: real-time typewriter AI streaming with rich formatting and verified source citations, with zero external runtime dependencies.
Output: SSE stream client, markdown renderer, citation badges, Vite production bundle, demo page, and bundle validation test suite.
</objective>

<threat_model>
- T-04-03: Stored and Reflected XSS through LLM responses or retrieved website content (ASVS 5.3). Mitigation: `renderMarkdown` applies strict `escapeHtml()` before parsing markdown entities, disallowing arbitrary HTML tags, `javascript:` URLs, and event handlers.
</threat_model>

<task type="auto">
  <name>Task 1: Native SSE Stream Client & Lightweight Markdown Parser</name>
  <files>widget/src/api/sseClient.js, widget/src/utils/markdown.js</files>
  <read_first>.planning/phases/03-control-backend-ingestion-job-queue/03-03-SUMMARY.md, .planning/research/PITFALLS.md</read_first>
  <action>
    1. Create `widget/src/utils/markdown.js`:
       - `escapeHtml(text)`: Converts `&`, `<`, `>`, `"`, `'` to HTML entities.
       - `renderMarkdown(markdownText)`:
         - Escapes raw HTML.
         - Converts code blocks (```` ```lang\ncode\n``` ````) into `<pre><code>...</code></pre>`.
         - Converts inline code (`` `code` ``) into `<code>...</code>`.
         - Converts bold (`**text**` / `__text__`) and italic (`*text*` / `_text_`).
         - Converts bullet lists (`- item` / `* item`) into `<ul><li>...</li></ul>`.
         - Converts links (`[text](url)`) into `<a href="url" target="_blank" rel="noopener noreferrer">text</a>`, rejecting non-http/https schemes.
         - Converts double newlines into `<p>` paragraphs.
    2. Create `widget/src/api/sseClient.js`:
       - Function `streamWidgetChat({ apiHost, widgetKey, message, sessionId, onToken, onCitations, onDone, onError })`:
         - Calls `fetch(`${apiHost}/api/v1/widget/chat`, { method: 'POST', headers: { 'Content-Type': 'application/json', 'x-widget-key': widgetKey }, body: JSON.stringify({ message, session_id: sessionId }) })`.
         - Checks for HTTP 403 (unauthorized origin) or HTTP 429 (rate limited) and invokes `onError()`.
         - Reads `response.body.getReader()` in a loop with `TextDecoder`.
         - Buffers incomplete SSE chunks and splits by `\n\n`.
         - Parses `data: JSON` lines: calls `onToken(data.token)` and captures `data.citations`.
         - Closes when `data: [DONE]` is received, invoking `onDone({ citations })`.
  </action>
  <verify>node -e "const { renderMarkdown } = require('./widget/src/utils/markdown'); console.log(renderMarkdown('**bold** `code`'))"</verify>
  <acceptance_criteria>
    - `renderMarkdown` converts bold, italic, code, and links with HTML escaping
    - `streamWidgetChat` handles token streaming and fires callbacks
  </acceptance_criteria>
  <done>SSE streaming client and zero-dependency markdown parser implemented.</done>
</task>
