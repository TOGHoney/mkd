<objective>
Scaffold the standalone embeddable chat widget in `widget/` using native Web Components (`HTMLElement`) and native Shadow DOM encapsulation (`attachShadow({ mode: 'open' })`). Construct the floating launcher button, responsive chat window layout, brand theme customization, and configuration retrieval.

Purpose: Guarantees 100% zero CSS leakage between the customer host website and the chat widget, ensuring consistent, pristine branding regardless of host framework styles (Tailwind, Bootstrap, or legacy CSS).
Output: Custom element `<supermemory-chat>`, Shadow DOM scoped styling, responsive window layout, and unit test suite.
</objective>

<threat_model>
- T-04-01: Host DOM manipulation and style collision (ASVS 14.2). Mitigation: Strict Shadow DOM encapsulation (`mode: 'open'`); maximum z-index `2147483647` on container with `position: fixed` ensures widget floats reliably above host site layers.
- T-04-02: Insecure parameter injection via script attributes (ASVS 5.1). Mitigation: Attributes `data-widget-key` and `data-api-host` sanitized; API requests strictly validated against URL schemes (`http`, `https`).
</threat_model>
