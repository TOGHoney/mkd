  <action>
    1. Update `ai-fastapi/requirements.txt` to include `groq>=0.11.0`.
    2. In `ai-fastapi/app/services/rag_service.py`:
       - Define models:
         ```python
         class Citation(BaseModel):
             title: str
             url: str
             heading: str
             score: float

         class RAGQueryRequest(BaseModel):
             workspace_id: str
             query: str
             conversation_history: List[Dict[str, str]] = []
             top_k: int = 5
             temperature: float = 0.2
         ```
       - Implement `RAGService`:
         - Uses `get_search_service()` to retrieve top-k chunks.
         - Deduplicates citations by URL and title.
         - Constructs grounded prompt:
           - System prompt: "You are a helpful, accurate AI assistant for this company. Answer the user's question STRICTLY based on the provided company documentation. If the answer cannot be found in the context, explicitly state: 'I am sorry, but based on the provided company materials, I do not have sufficient information to answer this question. Please reach out to customer support.' Do not speculate or make up information. Whenever referencing facts, cite the source name."
           - Assembles Context block:
             ```
             [SOURCE 1]: {title} ({source_url} > {heading})
             {text}
             ```
         - Connects to Groq via `AsyncGroq(api_key=settings.GROQ_API_KEY)` (or simulated streaming generator if API key is not yet provided).
         - Provides async generator `stream_rag_response(workspace_id, query, conversation_history)`:
           - Yields SSE formatted text tokens: `data: {"type": "token", "content": "..."}\n\n`
           - When generation completes, yields citation packet:
             `data: {"type": "citations", "sources": [...]}\n\n`
           - Concludes with `data: [DONE]\n\n`.
  </action>
