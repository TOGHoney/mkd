<objective>
Build the asynchronous website crawling and document extraction engine in FastAPI, equipped with sitemap discovery, HTML boilerplate stripping (navbars, footers, scripts, tracking widgets), markdown conversion, and SHA-256 document-level content hashing.

Purpose: Raw web pages contain excessive noise that pollutes vector embeddings. This engine extracts pure content and structure while guaranteeing safety against crawl loops and memory leaks.
Output: Production-grade crawler and cleaner modules with a testable `/api/v1/crawl` endpoint.
</objective>

    1. Define data classes:
       - `CrawlPage(url: str, title: str, markdown: str, content_hash: str, depth: int)`
       - `CrawlResult(base_url: str, total_pages: int, pages: List[CrawlPage], errors: List[dict])`
    2. Implement `WebCrawler` class:
       - Constructor accepting `base_url: str`, `max_depth: int = 3`, `max_pages: int = 50`, `timeout: float = 15.0`.
       - Normalize domain so the crawler never escapes the base origin (strict host domain fencing).
       - Implement `_fetch_sitemap(base_url: str) -> List[str]` trying `/sitemap.xml` and `/sitemap_index.xml` via `httpx.AsyncClient`.
       - Implement URL normalization stripping query params (`utm_*`, `ref`, session tokens) and hash fragments (`#`).
       - Implement `async crawl() -> CrawlResult`:
         - Initialize queue of URLs to visit starting with `base_url` (and sitemap links if found).
         - Track `visited_urls: Set[str]`.
         - Use `httpx.AsyncClient(follow_redirects=True, timeout=timeout)` for fast extraction.
         - For each valid HTML response, call `clean_html_to_markdown()`.
         - Extract new internal anchor tags (`<a href="...">`), filter against visited and max depth, and enqueue.
         - Stop immediately when `len(pages) >= max_pages` or queue is exhausted.
         - Include error logging without aborting the entire crawl on single-page 404s/timeouts.
  </action>
