Implement the hierarchical text chunker with contextual metadata injection, initialize the FastEmbed local embedding model (`BAAI/bge-small-en-v1.5`), and build the end-to-end ingestion pipeline in FastAPI (`POST /ingest`) that stores tenant-isolated vector records in Qdrant.

Purpose: Bridges raw documents and vector search. Chunks must carry their semantic origin (title, URL, heading) to prevent context fragmentation, and vectors must be tagged with `workspace_id` to guarantee tenant isolation.
Output: End-to-end working ingestion pipeline ready for direct document and crawled web indexing.
</objective>

    Create `ai-fastapi/app/services/chunking.py`:
    1. Define data model:
       ```python
       class DocumentChunk(BaseModel):
           chunk_id: str
           chunk_index: int
           text: str
           enriched_text: str  # Prepended with [Document: ... | Source: ...]
           token_count: int
           content_hash: str
           heading_context: str
       ```
    2. Implement `RecursiveChunker`:
       - Target chunk size: 600 tokens (approx 2400 chars).
       - Overlap: 100 tokens (approx 400 chars).
       - Cascading split delimiters: `["\n## ", "\n### ", "\n\n", "\n", ". ", " "]`.
       - Tracks active Markdown header breadcrumbs (`#`, `##`, `###`) to populate `heading_context`.
       - Formats `enriched_text` as:
         `[Document: {title} | Source: {source_url} | Section: {heading_context}]\n\n{chunk_text}`
       - Computes SHA-256 `content_hash` for each individual chunk.
    3. Implement function `chunk_document(title: str, source_url: str, markdown: str) -> List[DocumentChunk]`.
  </action>

         - Calls `chunk_document()`.

           - `vector`: 384-d float list
           - `payload`:
             ```json
             {
               "workspace_id": workspace_id,
               "source_id": source_id,
               "document_id": document_id,
               "chunk_id": chunk.chunk_id,
               "chunk_index": chunk.chunk_index,
               "title": title,
               "source_url": source_url,
               "heading_context": chunk.heading_context,
               "text": chunk.text,
               "enriched_text": chunk.enriched_text,
               "content_hash": chunk.content_hash,
               "created_at": iso_timestamp
             }
             ```
         - Performs batch upsert: `qdrant_client.upsert(collection_name=settings.QDRANT_COLLECTION_NAME, points=points)`.
