## 4. End-to-End User Flows

1. **Company Onboarding Flow:**
   Admin registers via Dashboard (`/auth/register`) → Auto-provisions default workspace with `sk_live_...` and `wk_live_...` → Lands on Workspace Overview (`DASH-01`).
2. **Knowledge Ingestion Flow:**
   Admin inputs documentation URL (`https://docs.acmecorp.com`) → Backend enqueues BullMQ crawl job (HTTP 202 Accepted) → FastAPI scrapes, extracts Markdown, chunks recursively, runs FastEmbed, and indexes into Qdrant → Admin monitors live SSE progress ticker (`DASH-02`).
3. **Widget Customization & Deployment Flow:**
   Admin selects brand color and sets bot name/avatar in Widget Designer with live preview (`DASH-03`) → Clicks "Get Embed Snippet" (`DASH-04`) → Adds website domain to Allowed Domains → Customer pastes `<script src=".../dist/widget.js" data-widget-key="..."></script>` on website.
4. **Visitor Question & Answer Flow:**
   Visitor opens chat on host site → Types question → Gateway validates Origin and rate limits → Proxies to FastAPI RAG engine → Retrieves top-k tenant-isolated chunks from Qdrant → Groq Llama 3.3 70B streams grounded answer with clickable citations → Interaction logged to Conversation Logs with latency metrics (`DASH-05`).
